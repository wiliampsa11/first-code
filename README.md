# First-Code

Mi primera web: un portafolio de proyectos de Diseño y Desarrollo Web del curso 2020-2021, con sección de proyectos, preguntas frecuentes y mapa del centro.

**Demo:** https://wiliampsa11.github.io/first-code/

## Tecnologías
- HTML5 y CSS3 (rejilla de columnas hecha a mano)
- Google Maps incrustado

## Estructura
```
index.html
css/styles.css
img/
```

## Cómo verlo
Abre `index.html` en el navegador o visita la demo.
